Lesson 0004 · Jenkins from zero

Start Jenkins Locally with Docker

You now have a real Jenkinsfile. The next win is understanding how a local Jenkins controller starts, how your browser reaches it, and where the first unlock password comes from.

The One Thing

When Jenkins runs in Docker, Docker starts a Jenkins container, publishes Jenkins on http://localhost:8080, and stores Jenkins data under /var/jenkins_home inside the container. A new Jenkins controller must be unlocked with the initial admin password before you can use the UI.

Sources: Installing Jenkins with Docker and Installing Jenkins.

The Setup Flow

1. Run containerJenkins starts as a local Docker container.
2. Publish port8080 in the container becomes 8080 on your machine.
3. Open browserYou visit http://localhost:8080.
4. UnlockYou paste the initial admin password into the setup wizard.

What Docker Gives You

A Docker image is the packaged Jenkins application. A Docker container is a running instance of that image. This is useful for learning because you can start Jenkins locally without installing it deeply into your operating system.

The official Jenkins Docker guide recommends the jenkins/jenkins image as the official Jenkins image and describes Docker-based setup steps.

What Jenkins Asks For

On first access, Jenkins shows the Unlock Jenkins page. The official docs say the password is generated automatically and can be read from Jenkins home, including this path when using Docker:

/var/jenkins_home/secrets/initialAdminPassword

Run Jenkins

For this beginner lesson, use the official Jenkins image directly. This starts Jenkins in the background, names the container jenkins-local, keeps Jenkins data in a Docker volume, and makes the web UI available on your machine at http://localhost:8080.

docker run --name jenkins-local \
  --detach \
  --publish 8080:8080 \
  --publish 50000:50000 \
  --volume jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts

If Docker says the name is already in use, you already have a container named jenkins-local. Ask the agent before deleting anything, because that container may contain previous Jenkins setup data.

The Password Command

If the container is named jenkins-local, this command prints the password you paste into the browser:

docker exec jenkins-local cat /var/jenkins_home/secrets/initialAdminPassword

Read it left to right: ask Docker to execute cat inside the running Jenkins container, then print the secret file.

Do Not Overlearn This Yet

The official Docker guide includes a more advanced Docker-in-Docker setup for Jenkins jobs that need to run Docker commands. For your current mission, the important beginner skill is simpler: know what a Jenkins container is, open the local UI, and unlock it.

Your Takeaway

You can now explain the first local Jenkins setup loop: start a Jenkins container, open localhost:8080, and unlock Jenkins with the generated password from /var/jenkins_home.
