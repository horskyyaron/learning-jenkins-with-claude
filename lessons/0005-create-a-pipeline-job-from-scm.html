Lesson 0005 · Jenkins from zero

Create a Pipeline Job From SCM

You have Jenkins running and a root-level Jenkinsfile. Now you need the missing link: a Jenkins Pipeline job that checks out a Git repository and runs that file.

The One Thing

A Jenkinsfile is used when a Jenkins Pipeline job is configured with Pipeline script from SCM. When you click Build Now, Jenkins checks out the repository, reads the configured Script Path, and executes the Pipeline from that file.

Sources: Getting started with Pipeline and Using a Jenkinsfile.

The Job Is the Connector

The Jenkinsfile is not run by a terminal command. The Jenkins job is the connector between Jenkins and your repository.

Pipeline job
  -> Git repository URL
  -> Script Path: Jenkinsfile
  -> Build Now
  -> Console Output

Container Reality Check

Your Jenkins is running inside a container. A folder on your Mac is not automatically visible inside that container. For Pipeline script from SCM, Jenkins needs a Git repository URL it can reach, such as a GitHub repository URL.

This workspace currently has no Git remote configured, so if you want Jenkins to run this exact repo through SCM, the practical next step is to push it to a Git host or add a reachable remote.

Classic UI Steps

From the Jenkins dashboard, click New Item.
Name it learning-jenkins, choose Pipeline, then click OK.
Scroll to the Pipeline section.
Set Definition to Pipeline script from SCM.
Set SCM to Git.
Paste a repository URL Jenkins can reach.
Set the branch, usually */main or */master.
Leave Script Path as Jenkinsfile.
Click Save, then Build Now.
Open build #1, then Console Output.

The Fields That Matter

These are the beginner fields to understand before changing anything else:

Definition:     Pipeline script from SCM
SCM:            Git
Repository URL: a Git URL Jenkins can reach
Branch:         */main or */master
Script Path:    Jenkinsfile

Script Path is the direct answer to “when does Jenkins use my Jenkinsfile?” Jenkins uses that path after checking out the repository during the job run.

Your Takeaway

The Jenkinsfile is used by a Pipeline job at build time. The job checks out SCM, reads Script Path: Jenkinsfile, and runs the stages in that file.
