Lesson 0001 · Jenkins from zero

Your First Jenkins Pipeline

Your goal is to build CI pipelines. The first win is learning to read the smallest useful Jenkins Pipeline: what runs, where it runs, and in what order.

The One Thing

A Jenkins Pipeline is an automated process, usually stored as a Jenkinsfile, that tells Jenkins how to build, test, and eventually deliver software. Jenkins recommends storing a Pipeline in source control so it can be reviewed, versioned, and treated as part of the project.

Sources: Jenkins Pipeline documentation and Using a Jenkinsfile.

Pipeline Vocabulary

JenkinsfileA text file in your repository that defines the Pipeline.
pipelineThe top-level block for a Declarative Pipeline.
agentWhere Jenkins should run the work. agent any means any available agent.
stagesThe ordered collection of major phases.
stageOne named phase, such as Build or Test.
stepsThe actual tasks Jenkins executes inside a stage.

The Mental Model

Read a beginner Jenkinsfile like a checklist:

Pipeline: here is the whole automation.

Agent: choose a machine to run on.

Stages: run these phases in order.

Steps: execute these exact actions.

The Jenkins docs define a stage as a distinct subset of tasks and a step as a single task that tells Jenkins what to do.

Read This Jenkinsfile

This does not build a real app yet. It is a safe first skeleton for learning the shape.

pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                echo 'Building...'
            }
        }

        stage('Test') {
            steps {
                echo 'Testing...'
            }
        }
    }
}

Practice

1. Which line tells Jenkins where it may run the Pipeline?

2. What order will the two stages run in?

3. Which step runs inside the Test stage?

Your Takeaway

If you can identify the agent, stages, and steps, you can read the basic shape of a Jenkins CI pipeline. Next session, you can turn this skeleton into a real local Jenkinsfile with an actual command.

Ask the agent follow-up questions if any term is unclear. Good questions: “Why is agent required?” or “What changes when a step fails?”
