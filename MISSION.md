# Mission: Jenkins

## Why
Learn Jenkins from zero so you can build, read, and maintain CI pipelines for software projects.

## Success looks like
- You can explain what a Jenkins Pipeline does and why teams store it in a `Jenkinsfile`.
- You can create a simple Declarative Pipeline with build and test stages.
- You can connect a repository to Jenkins and diagnose basic pipeline failures from the console output.

## Constraints
- Start from total beginner level.
- Prefer short, practical lessons with a concrete win each session.
- Use high-trust Jenkins documentation as the source of truth.

## Out of scope
- Jenkins administration at scale, plugin development, and advanced deployment automation until the CI pipeline basics are solid.
