Console Output Reading Loop

Quick reference for reading a Jenkins Pipeline run without getting lost.

Core rule: read console output in order: trigger, checkout, stage output, final result.

Four-Pass Scan

PassQuestionLook for
TriggerWhy did this run start?User, webhook, branch indexing, timer, or upstream job.
CheckoutDid Jenkins fetch the right code?Repository URL, branch, commit, workspace path.
StagesWhich Pipeline steps ran?[Pipeline] stage, [Pipeline] sh, command output.
ResultDid the run succeed?Finished: SUCCESS, FAILURE, or UNSTABLE.

[Pipeline] stage

Finished: SUCCESS

First Failure Rule

When a run fails, find the first command output or error before Finished: FAILURE. The final line tells you the result; the useful cause is usually earlier.
