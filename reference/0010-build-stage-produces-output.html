Build Stage Produces Output

Quick reference for the first meaningful Jenkins Build stage.

Core rule: a beginner Build stage should produce something concrete; a Test stage should verify an expectation about it.

Build Stage

stage('Build') {
    steps {
        sh 'mkdir -p build'
        sh 'printf "Jenkins learning workspace\n" > build/summary.txt'
        sh 'ls build'
    }
}

Test Stage Addition

sh 'test -f build/summary.txt'

Command Meanings

CommandMeaning
mkdir -p buildCreate the build output directory if it does not exist.
printf ... > build/summary.txtCreate a small generated file inside the build directory.
ls buildPrint the build output so the console proves what was created.
test -f build/summary.txtFail the build if the expected generated file is missing.
