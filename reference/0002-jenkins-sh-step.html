Jenkins sh Step

Quick reference for turning Pipeline stages into real CI work.

Core rule: Use sh inside steps to run a shell command on the Jenkins agent. A non-zero exit status normally fails the step.

Basic Pattern

stage('Test') {
    steps {
        sh 'npm test'
    }
}

Common Beginner Commands

GoalCommandWhy use it?
Show workspace pathsh 'pwd'Confirms where the agent is running.
List filessh 'ls'Confirms what Jenkins can see.
Node.js testssh 'npm test'Runs the test script from package.json.
Maven testssh 'mvn test'Runs Java tests in a Maven project.
Python testssh 'pytest'Runs tests discovered by pytest.

Do Not Confuse

SyntaxMeaning
echo 'Testing...'Jenkins prints a message.
sh 'echo Testing...'The agent shell runs the echo command.
sh 'exit 1'The shell returns failure, so Jenkins normally fails the step.
