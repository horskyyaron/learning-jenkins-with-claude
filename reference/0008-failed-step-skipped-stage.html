Failed Step, Skipped Stage

Quick reference for default Pipeline failure flow.

Core rule: a failed normal step stops the current path of work. Later normal steps and stages do not run unless the Jenkinsfile explicitly handles the failure.

Default Flow

EventDefault result
sh 'exit 1'The sh step fails because the shell returned nonzero.
More steps in same stageSkipped.
Later normal stagesSkipped due to earlier failure.
Final build resultFinished: FAILURE.

What Can Still Run?

A Declarative post block can run after a stage or Pipeline completes. For example, post { always { ... } } runs regardless of success or failure.
