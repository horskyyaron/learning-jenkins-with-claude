Local Jenkins Docker Setup

Quick reference for starting Jenkins locally and unlocking the setup wizard.

Core rule: a Jenkins container is a local Jenkins controller. After it starts, open http://localhost:8080 and unlock it with the initial admin password from the container.

Minimal Learning Flow

StepWhat to check
Start JenkinsRun a Jenkins container that publishes container port 8080 to host port 8080.
Open the UIBrowse to http://localhost:8080 and wait for the Unlock Jenkins screen.
Get the passwordRead /var/jenkins_home/secrets/initialAdminPassword inside the container.
Finish setupInstall suggested plugins and create the first admin user.

Run Jenkins

docker run --name jenkins-local \
  --detach \
  --publish 8080:8080 \
  --publish 50000:50000 \
  --volume jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts
PartMeaning
--name jenkins-localGives the container a stable name for later commands.
--detachRuns Jenkins in the background.
--publish 8080:8080Makes the Jenkins web UI available at http://localhost:8080.
--publish 50000:50000Publishes the default inbound agent port; not important for the first beginner run.
--volume jenkins_home:/var/jenkins_homePersists Jenkins home in a Docker volume.
jenkins/jenkins:ltsUses the official Jenkins long-term support image.

Password Command

docker exec jenkins-local cat /var/jenkins_home/secrets/initialAdminPassword

Beginner Vocabulary

TermMeaning
ImageThe packaged Jenkins application Docker can download and run.
ContainerA running instance of the Jenkins image.
Port publishA mapping that lets your browser reach Jenkins in the container.
Jenkins homeThe directory where Jenkins stores configuration, secrets, jobs, and build history.
