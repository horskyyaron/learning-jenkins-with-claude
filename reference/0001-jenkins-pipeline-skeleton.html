Jenkins Pipeline Skeleton

A quick reference for reading and writing your first Declarative Jenkinsfile.

Reading rule: A basic Jenkinsfile says where to run work, which stages to run, and which steps happen inside each stage.

Minimal Shape

pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                echo 'Building...'
            }
        }

        stage('Test') {
            steps {
                echo 'Testing...'
            }
        }
    }
}

Terms

TermMeaningBeginner question
JenkinsfilePipeline definition stored as code in the repository.What automation belongs with this project?
pipelineTop-level Declarative Pipeline block.Where does the whole automation start?
agentMachine or environment where Jenkins runs the work.Where can this run?
stagesContainer for the ordered phases.What phases exist?
stageOne named phase, often Build, Test, or Deploy.What is this phase trying to prove?
stepsConcrete tasks Jenkins executes.What command or Jenkins action happens?
