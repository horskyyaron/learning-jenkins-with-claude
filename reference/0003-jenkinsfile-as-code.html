Jenkinsfile As Code

Quick reference for the first repository-level Jenkins pipeline file.

Core rule: Put a file named Jenkinsfile at the repository root so Jenkins can read the Pipeline definition from source control.

Starter File

pipeline {
    agent any

    stages {
        stage('Inspect') {
            steps {
                sh 'pwd'
                sh 'ls'
            }
        }

        stage('Test') {
            steps {
                sh 'echo No tests configured yet'
            }
        }
    }
}

Why Store It In Git?

BenefitWhat it means
ReviewPipeline changes can be reviewed like application code.
HistoryYou can see when and why CI behavior changed.
Single source of truthThe pipeline definition lives with the project it builds.
Branch behaviorBranches and pull requests can carry their own pipeline changes in Jenkins setups that support it.

Beginner Checklist

CheckWhy
File is named exactly JenkinsfileJenkins examples and conventions use this exact name.
File is at repository rootMakes the CI entry point easy to find.
Uses agent anyLets a beginner pipeline run on any available agent.
Has at least one real sh stepProves Jenkins can run commands, not just print messages.
