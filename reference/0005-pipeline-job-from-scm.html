Pipeline Job From SCM

Quick reference for making Jenkins read a repository-hosted Jenkinsfile.

Core rule: the Jenkinsfile is used when a Pipeline job is configured with Pipeline script from SCM and the job is run.

Classic UI Fields

FieldBeginner value
New Item typePipeline
DefinitionPipeline script from SCM
SCMGit
Repository URLA Git URL the Jenkins container can reach
Branch SpecifierUsually */main or */master
Script PathJenkinsfile

Run Flow

ActionWhat Jenkins does
Click SaveStores the job configuration in Jenkins home.
Click Build NowChecks out the repository.
Read JenkinsfileLoads the Pipeline definition from the configured script path.
Open Console OutputShows each stage and command output.

Important Constraint

A local path on your Mac is not automatically visible inside the Jenkins container. For the beginner SCM path, push the repository to a Git host or otherwise provide a URL Jenkins can reach.
