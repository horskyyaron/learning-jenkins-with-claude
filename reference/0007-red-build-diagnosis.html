Red Build Diagnosis

Quick reference for a controlled Jenkins failure.

Core rule: if an sh command exits nonzero, Jenkins normally fails that step and the Pipeline becomes red.

Controlled Failure

stage('Test') {
    steps {
        sh 'echo About to fail on purpose'
        sh 'exit 1'
    }
}

Diagnosis Loop

QuestionEvidence
Which stage failed?Find the last open [Pipeline] { (Stage Name) before the error.
Which command failed?Find the last + shell command before the error.
Why did Jenkins fail it?Look for a nonzero exit status or command error.
How do I restore green?Replace the failing command, commit, push, and build again.

Expected Clues

+ exit 1
script returned exit code 1
Finished: FAILURE
