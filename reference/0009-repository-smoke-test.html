Repository Smoke Test

Quick reference for replacing a placeholder Jenkins test stage.

Core rule: a smoke test is a small check that proves the pipeline can see the expected project shape after checkout.

Current Test Stage

stage('Test') {
    steps {
        sh 'test -f Jenkinsfile'
        sh 'test -d lessons'
        sh 'test -d reference'
    }
}

Command Meanings

CommandPasses whenFails when
test -f JenkinsfileJenkinsfile exists and is a file.The CI entry point is missing or not a file.
test -d lessonslessons exists and is a directory.The lesson archive is missing or not a directory.
test -d referencereference exists and is a directory.The reference archive is missing or not a directory.

Why This Is Better Than Echo

echo only proves Jenkins can print text. test proves something about the checked-out repository and fails automatically when the expectation is false.
